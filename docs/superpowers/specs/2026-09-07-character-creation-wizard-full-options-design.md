# Дизайн-спецификация: Полная поддержка выборов 1-го уровня для всех рас и классов в мастере создания персонажа D&D 5e

## 1. Цели и назначение
Обеспечить 100% покрытие правил D&D 5e (SRD 5.1 / PHB / TCE) на 1-м уровне создания персонажа в интерактивном мастере (`CharacterCreationWizardModal.tsx`):
1. **Устранение дефекта замены навыков предыстории:** Корректная работа `<select>` при совпадении навыков предыстории с классом/расой без сброса выбора в дефолтное состояние.
2. **Блокировка генерации имени до выбора расы:** Поле ввода имени и кнопка 🎲 заблокированы до выбора расы; генерация имени использует генератор, привязанный к выбранной расе.
3. **Классовые выборы 1-го уровня:**
   - **Воин (Fighter):** Выбор 1 Боевого стиля из 6 (*Стрельба, Оборона, Дуэлянт, Оружие в обеих руках, Защита, Бой большим оружием*).
   - **Плут (Rogue):** Выбор 2 навыков для Компетентности / Экспертизы (*удвоение бонуса мастерства*).
   - **Следопыт (Ranger):** Выбор Избранного врага и Любимой местности.
   - **Чародей (Sorcerer - Драконья кровь):** Выбор Драконьего предка (*цвет дракона, определяющий тип стихийного урона дыхания и сопротивления*).
   - **Жрец (Cleric):** Поддержка доменных выборов на 1-м уровне (*например, заговор друида и навык для Домена Природы*).
4. **Расовые выборы 1-го уровня:**
   - **Вариантный человек (Variant Human):** Выбор 1 стартовой Черты (Feat) из компендиума черт + 1 навык + 2 характеристики.
   - **Кастомная родословная (Custom Lineage - TCE):** Выбор 1 стартовой Черты + Тёмное зрение/навык + характеристика.
   - **Драконорождённый (Dragonborn):** Выбор Драконьего наследия (цвет дракона, урон дыхания и сопротивление).
   - **Высший эльф (High Elf):** Выбор 1 дополнительного заговора волшебника (INT).
   - **Дворф (Dwarf):** Выбор 1 ремесленного инструмента (кузнец, каменщик, пивовар).
   - **Расы с выбором навыков:** Кенку, Людоящер, Чанглинг, Леонинец, Тортл, Полуэльф.
5. **Интерактивный выбор дополнительных языков (чекбоксы):**
   - Выбор доступного числа языков из стандартного и экзотического наборов D&D 5e с защитой от повторного выбора уже известных языков.

## 2. Архитектура компонентов и данных

### 2.1. Расширение `src/components/wizard/wizard-helpers.ts`
- Добавление каталогов правил для выборов 1-го уровня:
  - `FIGHTING_STYLES`: список боевых стилей Воина (id, name, description, bonus).
  - `DRAGON_ANCESTRIES`: список 10 драконьих предков (color, damageType, breathShape, saveAbility).
  - `RANGER_FAVORED_ENEMIES` и `RANGER_FAVORED_TERRAINS`.
  - `DWARF_TOOL_OPTIONS`: ['Инструменты кузнеца', 'Инструменты каменщика', 'Инструменты пивовара'].
  - `STANDARD_LANGUAGES` и `EXOTIC_LANGUAGES`: списки языков D&D 5e.
- Функции получения конфигурации выбора расы:
  - `getRacialChoicesConfig(race, subrace)`: возвращает флаги и лимиты для черт, заговоров, инструментов, стихий дыхания и языков.
- Функции получения конфигурации выбора класса:
  - `getClassLevel1ChoicesConfig(className, subclassId)`: возвращает флаги и списки для боевого стиля, экспертизы, врагов/местности, предка.

### 2.2. Расширение состояния в `CharacterCreationWizardModal.tsx`
- Расовые выборы:
  - `selectedRacialFeatId: string` — выбранная черта.
  - `selectedRacialCantrip: string` — дополнительный расовый заговор (Высший эльф).
  - `selectedRacialTool: string` — выбранный инструмент (Дворф).
  - `selectedDragonColor: string` — цвет дракона (Драконорождённый / Драконий чародей).
  - `selectedExtraLanguages: string[]` — выбранные дополнительные языки.
- Классовые выборы:
  - `selectedFightingStyle: string` — выбранный боевой стиль (Воин).
  - `selectedExpertise: string[]` — выбранные 2 навыка для экспертизы (Плут).
  - `selectedFavoredEnemy: string` — избранный враг (Следопыт).
  - `selectedFavoredTerrain: string` — любимая местность (Следопыт).

### 2.3. Исправление дефекта `backgroundSkillReplacements`
- Опции для выпадающего списка замены навыка предыстории фильтруются так, чтобы текущая выбранная замена (`replacement`) оставалась в списке `<option>`, не приводя к сбросу в дефолт.
- Визуальный статус обновляется на `✓ Заменён на «[Навык]»` с сохранением возможности повторного изменения.
