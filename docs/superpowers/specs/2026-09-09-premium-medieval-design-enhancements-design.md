# Спецификация: Премиальные дизайн-улучшения D&D 5e Character Sheet (по мотивам Taste-Skill & GPT-Taste)

**Дата:** 2026-09-09  
**Тема:** Внедрение тактильной физики, разгрузка панели управления, слоистая глубина пергамента и живые пустые состояния с сохранением Parchment Medieval Theme (`AGENTS.md`)  
**Классификация:** Architectural  
**Статус:** На утверждении  

---

## 1. Контекст и цели

На основе анализа дизайн-инженерных скиллов (`taste-skill`, `design-taste-frontend`, `design-taste-frontend-v1`, `gpt-taste`), адаптированных под требования интерактивного листа персонажа D&D 5e:
- Сохранить на 100% строгую средневековую тему пергамента (`AGENTS.md`): чернила `#3D2012`, пергамент `#F5E6C8`, античное золото `#C9A84C`. Категорический запрет на плоские серые плашки, чисто белый фон и браузерный синий фокус.
- Устранить визуальную перегрузку десктопной шапки (9 кнопок в ряд).
- Добавить тактильную физику нажатий и пружинную анимацию броска d20 (`framer-motion`).
- Внедрить скользящий индикатор переключения вкладок.
- Заменить холодные тени на глубокие чернильно-янтарные тени дубового стола с внутренним тиснением сусальным золотом.
- Оформить пустые состояния инвентаря, атак и книги заклинаний в виде атмосферных гравюрных штампов с векторными иконками.

## 2. Архитектурные разделы дизайна

### 2.1. Физика бросков d20 и тактильный отклик (Spring Physics & Tactility)
1. **Пружинный бросок d20 в `RollResultPopup`:**
   - Использовать `framer-motion` (уже установлен в проекте `^12.23.2`).
   - При срабатывании броска: карточка результата мягко выкатывается с пружинным эффектом (`type: "spring", stiffness: 220, damping: 18`).
   - Иконка двадцатигранника d20 совершает энергичный микро-оборот (`rotate: [0, 360]`), а выпавшее число пульсирует.
   - Для натуральной 20 (критический успех): мягкое золотистое свечение `rgba(201, 168, 76, 0.45)`.
   - Для натуральной 1 (критический провал): багряное чернильное свечение `rgba(139, 37, 0, 0.35)`.
2. **Тактильный клик по кнопкам и сургучным печатям:**
   - В `.parchment-btn`, `.parchment-btn-secondary`, `.roll-badge` добавить активное состояние: `active:scale-[0.98] active:translate-y-[1px]`.
   - Это имитирует физический оттиск сургучной печати или штампа на плотной бумаге.
3. **Скользящие вкладки (Sliding Tab Indicator):**
   - Во вкладках «Основной лист», «Детали», «Заклинания» добавить плавный переход активной плашки через `motion.span layoutId="activeTabParchment"`.

### 2.2. Архитектурная разгрузка шапки (Header De-Cluttering & Vintage Menu)
- **Проблема:** Сейчас 9 кнопок стоят в один ряд: `+ Создать персонажа`, `Шаблоны`, `JSON`, `Загрузить JSON`, `Сброс`, `Персонажи`, `Поделиться`, `Войти`, `Экспорт DOCX`.
- **Решение:**
  1. **Главная доминанта (Primary CTA):** Кнопка `+ Создать персонажа` (акцентный золотой градиент, выделяется как ключевое действие).
  2. **Выпадающее меню «Свиток / Лист» (`parchment-menu-dropdown`):**
     - Компактная кнопка с иконкой `ScrollIcon` и стрелочкой вниз.
     - Содержит вторичные действия управления бланком:
       - 📜 Выбрать шаблон класса (`handleApplyTemplate`)
       - 💾 Сохранить в JSON (`handleSaveJSON`)
       - 📥 Загрузить из JSON (`handleLoadJSON`)
       - ⏳ Сбросить бланк (`handleReset`)
     - Закрывается по клику вне меню и по Escape.
  3. **Группа облака и профиля:** Кнопки `Персонажи`, `Поделиться`, `Войти / Профиль`.
  4. **Экспорт:** Кнопка `Экспорт DOCX` (перо с чернилами).
- **Результат:** Верхняя панель становится чистой, организованной, без перегруза и каши.

### 2.3. Слоистая глубина пергамента и золотое тиснение (Materiality & Shadows)
1. **Тени:**
   - В `src/app/globals.css` обновить тени `.parchment-card`, `.parchment-modal`, `.parchment-header`:
     `box-shadow: 0 4px 20px rgba(60, 36, 21, 0.22), inset 0 1px 0 rgba(255, 240, 200, 0.4);`
   - Тени приобретают благородный оттенок натурального дуба и пергамента вместо искусственной серости.
2. **Внутреннее тиснение сусальным золотом:**
   - На заголовках карточек `.parchment-heading` и золотых кнопках добавить тонкий световой блик `border-t border-[#FFE58F]/40` и мягкое свечение.

### 2.4. Атмосферные пустые состояния (Alive Empty States)
- Для списков, когда у персонажа еще нет записей:
  1. **Оружие и атаки:** Гравюрный контур скрещенных мечей `<CrossedSwordsIcon size={32} />` с подписью: *«Оружие еще не экипировано. Нажмите „+ Оружие“, чтобы добавить боевой арсенал»*.
  2. **Снаряжение:** Контур походного мешка `<BackpackPackIcon size={32} />` с подписью: *«Походная сумка пуста. Добавьте экипировку из приключения»*.
  3. **Книга заклинаний:** Контур фолианта `<SpellbookIcon size={32} />` с подписью: *«Книга заклинаний пуста. Добавьте чары или выберите класс-заклинатель»*.
  4. **Черты и особенности:** Контур свитка `<ScrollIcon size={32} />` с подписью: *«Особенности персонажа формируются расой, классом и предысторией»*.
