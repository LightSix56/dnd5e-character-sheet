# 📜 Спецификация дизайна: Модульный компендиум рас D&D 5e и автогенерация choices

## 1. Цель и контекст
Объединить 76 официальных рас и 79 подрас D&D 5e (ранее спарсенных с dnd.su в `.dndsu-cache/all-official-races.json`) с существующим компендиумом проекта `src/data/compendium/races.ts`, используя новую универсальную систему расовых развилок `choices: RaceChoicesConfig`.

### Ключевые требования:
1. **Сохранение качества (Zero Regression)**: Не затирать существующие отполированные базовые расы (PHB).
2. **Разделение версий из разных книг (No Collisions)**: Если раса издавалась в нескольких книгах (например, Аасимар в VGM и в MPMM, Кобольд в VGM и в MPMM), обе версии должны быть доступны игроку:
   - Оригинал: `id: 'aasimar'`, `source: 'Volo\'s guide to monsters'`
   - Версия MPMM: `id: 'aasimar-mpmm'`, `name: 'Аасимар (MPMM)'`, `source: 'Monsters of the Multiverse'`
3. **Модульная файловая архитектура**: Разделить растущую базу рас на логические модули в папке `src/data/compendium/races/`, сохранив `src/data/compendium/races.ts` как фасад для 100% обратной совместимости импортов по всему проекту.
4. **Автоматический и точный маппинг `choices`**: Все особые расовые выборы (размеры, заговоры, характеристики магии, инструменты, навыки, черты, кастомные фичи) должны быть корректно прописаны в объектах рас.

## 2. Архитектура файлов и модулей

Вместо одного монолитного файла на 500 КБ создается модульная структура в `src/data/compendium/races/`:

```
src/data/compendium/races/
├── types.ts           # Интерфейсы: CompendiumRace, CompendiumSubrace, RaceChoicesConfig, MagicClass и т.д.
├── core.ts            # Базовые расы Player's Handbook (Человек, Эльф, Дварф, Хафлинг, Гном, Драконорождённый, Полуэльф, Полуорк, Тифлинг, Кастомное происхождение TCoE)
├── multiverse.ts      # 33 расы из Monsters of the Multiverse (MPMM) с правилами +2/+1, выбором размера и актуальными трейтами
├── supplements.ts     # Расы сеттингов и дополнений (Эберрон, Равника, Терос, Стриксхейвен, Spelljammer, Dragonlance, Ravenloft и др.)
└── index.ts           # Сборка единого массива DND_COMPENDIUM_RACES, хелперы getCompendiumRaceById и т.д.
```

Входная точка `src/data/compendium/races.ts`:
```typescript
export * from './races/index';
export * from './races/types';
```
Все внешние компоненты (`CharacterCreationWizardModal`, `CompendiumRaceModal`, тесты, селекторы) продолжают импортировать из `@/data/compendium/races` без каких-либо изменений путей.

## 3. Правила определения `choices: RaceChoicesConfig`

Скрипт слияния анализирует особенности рас и заполняет `choices`:

| Тип выбора | Логика определения | Примеры рас |
|---|---|---|
| `sizeChoice: ['Средний', 'Маленький']` | Текст черты «Размер» содержит «Средний или Маленький» | Зайцегон, Фэйри, Совлин, Гоблин (MPMM), Кобольд (MPMM) |
| `isFlexibleASI: true` | Источник MPMM/TCoE либо текст «Увеличьте одну на 2...» | Все расы MPMM, Кастомное происхождение |
| `cantripChoice` | Особенность дарует заговор на выбор заданного класса | Кобольд MPMM (`sorcerer`, выбор ИНТ/МДР/ХАР), Высший эльф (`wizard`), Астральный эльф (фиксированный пул из 3) |
| `toolChoice` | Владение инструментами на выбор | Дварф (`dwarf_tools`), Автогном (`artisan` x2), Человек с меткой создания (`artisan`) |
| `extraSkillsCount` + `skillChoiceOptions` | Выбор навыков из общего или ограниченного пула | Полуэльф (2 любых), Кенку MPMM (2 любых), Чейнджлинг (2 из 4), Леонинец (1 из 4), Ящеролюд (2 из 5) |
| `hasFeat: true` | Доступ к черте на 1 уровне | Вариантный человек, Кастомное происхождение |
| `customFeatureChoice` | Развилки уникальных расовых свойств | Гибрид Симиков (улучшения животных на 1 и 5 ур.), Шифтер (подвиды), Эладрин (сезоны) |
| `extraLanguagesCount` | Дополнительные языки на выбор | Расы с чертой «Один дополнительный язык на ваш выбор» |

## 4. Скрипт слияния (`scripts/merge-races-compendium.ts`)

Скрипт выполняет следующие этапы:
1. Загружает текущий `DND_COMPENDIUM_RACES`.
2. Загружает `.dndsu-cache/all-official-races.json`.
3. Сопоставляет расы:
   - Базовые расы (PHB): сохраняет существующие отполированные тексты, обогащает отсутствующими подрасами.
   - Дубликаты из других книг (MPMM / VGM / Eberron): разводит по уникальным ID (`${id}-mpmm`), добавляя суффикс книги к названию.
   - Новые расы: парсит поля (скорость, размер, зрение, трейты, подрасы), форматирует AbilityBonuses в `{ str?: 2, dex?: 1 }`, формирует `choices`.
4. Поддерживает флаг `--dry-run`:
   - Выводит структурированную сводку: сколько рас в каждой категории, какие `choices` сгенерированы, список новых рас и предупреждений.
5. При запуске без `--dry-run`:
   - Форматирует TypeScript код и сохраняет в `src/data/compendium/races/core.ts`, `multiverse.ts`, `supplements.ts`, `types.ts`, `index.ts`.
