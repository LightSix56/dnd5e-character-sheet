# Спецификация: Конструктор предметов и движок динамических магических эффектов

## 1. Обзор и цели

Цель разработки — предоставить игроку и Мастеру гибкий инструмент создания уникальных магических предметов (артефактов, зачарованного снаряжения, реликвий, проклятых предметов) с поддержкой:
1. Полной отмены жестко закодированных статических полей («бонусное КД», «бонусная скорость») в пользу динамического конструктора эффектов (`+ Добавить эффект`).
2. Поддержки положительных и отрицательных числовых эффектов (+1, -2, +10 и т.д.) и произвольных свойств от Мастера.
3. Долговечного сохранения созданных предметов в инвентаре персонажа (`char.customItems`), чтобы снятый предмет не терялся, а оставался доступен для повторного надевания или окончательного удаления/продажи.
4. Реактивного пересчета параметров листа персонажа в реальном времени (КД, скорость, характеристики, максимальные хиты, атаки оружием, спасброски заклинаний).
5. Автоматической инъекции свойств надетых предметов в карточку **«Умения и особенности»** (`effectiveTraitsList`) с бейджем источника `🎒 Предмет: [Название]` и мгновенным удалением при снятии предмета.

## 2. Архитектура модели данных

### 2.1. Типы эффектов (`ItemEffect`)
Файл: `src/lib/equipment-types.ts`

```typescript
export type ItemEffectType =
  | 'ac'             // Класс Доспеха (+1, +2, -1)
  | 'speed'          // Скорость в футах (+10, -5)
  | 'hpMax'          // Максимальные хиты (+10, -5)
  | 'attackDamage'   // Бонус к атаке и урону оружия (+1, +2, +3)
  | 'spellDC'        // Сложность спасбросков заклинаний и атака заклинанием (+1, +2)
  | 'ability'        // Бонус к характеристике (+2 к Силе, -1 к Ловкости)
  | 'savingThrows'   // Бонус ко всем спасброскам (+1)
  | 'customTrait';   // Произвольное свойство от Мастера (текст + описание)

export interface ItemEffect {
  id: string;
  type: ItemEffectType;
  targetAbility?: AbilityName; // 'str' | 'dex' | 'con' | 'int' | 'wis' | 'cha'
  value: number | string;      // Число (+1, -2) или название особенности
  description?: string;        // Опциональное описание правила
  customName?: string;         // Имя особенности от ДМа (для customTrait)
}
```

### 2.2. Расширение структуры предмета (`EquippedItem`)
```typescript
export interface EquippedItem {
  id: string;
  name: string;
  slot: EquipmentSlotId;
  description?: string;
  rarity?: string;
  weight?: number;
  twoHanded?: boolean;
  isShield?: boolean;
  effects?: ItemEffect[];
  // Обратная совместимость для компендиума:
  bonusAC?: number;
  bonusSpeed?: number;
  bonusAttack?: number;
  bonusDamage?: number;
}
```

### 2.3. Хранение в объекте персонажа (`CharacterData`)
Файл: `src/lib/dnd-types.ts`

```typescript
export interface CharacterData {
  // ... существующие поля ...
  equippedSlots?: Partial<Record<EquipmentSlotId, EquippedItem>>;
  customItems?: EquippedItem[]; // Персональная коллекция созданных предметов
}
```

## 3. Пользовательский интерфейс: Конструктор предмета

### 3.1. Вкладка «Свой предмет» в `EquipmentSlotModal.tsx`
- **Заголовок слота:** Иконка и название текущего слота (например, `👑 Голова / Шлем`).
- **Основные реквизиты:**
  - `Название предмета *` (`parchment-input-boxed`, обязательно).
  - `Редкость` (`parchment-select`: Обычный, Необычный, Редкий, Очень редкий, Легендарный, Артефакт).
  - `Вес (фнт.)` (`parchment-input-boxed`, шаг 0.5).
  - Для слота `mainHand`: чекбокс «Двуручное оружие» (блокирует вторую руку).
  - Для слота `offHand`: чекбокс «Считается щитом» (+2 КД по правилам).
- **Раздел «Магические эффекты и свойства»:**
  - Кнопка `[+ Добавить эффект]`.
  - Список добавленных эффектов (каждый оформлен отдельной строкой/карточкой на пергаментном фоне):
    - Селектор типа эффекта с понятными эмодзи.
    - Для типа `ability`: селектор характеристики (Сила, Ловкость, Телосложение, Интеллект, Мудрость, Харизма).
    - Поле ввода значения:
      - Для числовых типов — число со стрелками/степпером и поддержкой отрицательных чисел.
      - Для свойства от Мастера — текстовое поле названия особенности (например, *«Ночное зрение 60 фт.»*).
    - Текстовое поле `Описание (опционально)`: для пояснения правила действия эффекта.
    - Кнопка удаления строки `✕` (`.parchment-remove-btn`).
- **Кнопка сохранения:** `[✨ Создать и экипировать]`.

### 3.2. Отображение сохраненных предметов персонажа
- В модальном окне слота на вкладке «Компендиум» (или выделенной секции) выводится блок **«🎒 Мои созданные предметы»** (отфильтрованные по текущему слоту из `char.customItems`).
- Для каждого сохранённого предмета отображаются:
  - Название, бейдж редкости, список активных эффектов (+1 КД, +10 фт. и т.д.).
  - Кнопка **[Экипировать]** (или «Надето», если предмет уже на кукле).
  - Кнопка **[🗑️ Удалить]** (с подтверждением для окончательного удаления из инвентаря).

## 4. Движок применения эффектов (Reactivity Engine)

### 4.1. Централизованный калькулятор `calculateEquipmentBonuses(char)`
Файл: `src/lib/equipment-types.ts`
Возвращает агрегированный объект:
```typescript
export interface EquipmentBonusesSummary {
  acBonus: number;
  speedBonus: number;
  hpMaxBonus: number;
  abilityBonuses: Record<AbilityName, number>;
  attackBonus: number;
  damageBonus: number;
  spellDCBonus: number;
  savingThrowsBonus: number;
  itemTraits: TraitItem[];
}
```

### 4.2. Точки интеграции в логику листа персонажа:
1. **КД (`getAC` в `src/lib/dnd-types.ts`):**
   - Учитывает `bonuses.acBonus` поверх базовой формулы брони, ловкости и щита.
2. **Скорость (`getEffectiveSpeed` в `src/lib/dnd-types.ts`):**
   - Прибавляет `bonuses.speedBonus`.
3. **Характеристики (`getTotalScore` в `src/lib/dnd-types.ts`):**
   - Добавляет `bonuses.abilityBonuses[ability]`, что мгновенно меняет модификаторы и зависимые навыки/спасброски.
4. **Максимум здоровья (HP):**
   - При расчете/отображении максимальных хитов добавляется `bonuses.hpMaxBonus`.
5. **Атаки оружием (`getActiveCharacterAttacks` в `src/lib/equipment-types.ts`):**
   - Учитывает зачарование экипированного оружия (`attackBonus`, `damageBonus`).
6. **Сложность спасбросков заклинаний и магическая атака:**
   - В компонентах заклинаний добавляется `bonuses.spellDCBonus`.
7. **Способности персонажа (`effectiveTraitsList` в `src/app/page.tsx`):**
   - Автоматически объединяет `char.traitsList` с `bonuses.itemTraits`.
   - Бейдж источника: `🎒 Экипировка: [Название предмета]`.
   - При снятии предмета свойство автоматически исчезает.
