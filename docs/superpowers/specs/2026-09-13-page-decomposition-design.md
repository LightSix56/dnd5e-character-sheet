# Спецификация: Декомпозиция монолита page.tsx в модульную архитектуру

**Дата**: 2026-09-13  
**Статус**: Утверждено  
**Цель**: Безопасный рефакторинг файла `src/app/page.tsx` (4790 строк) в масштабируемую модульную архитектуру компонентов и хуков листа персонажа с сохранением 100% функционала, визуального стиля и стабильности.

---

## 1. Проблема и Контекст

Текущий файл `src/app/page.tsx` разросся до **4790 строк**, выполняя слишком много задач одновременно:
1. Хранит и синхронизирует все состояние персонажа (`CharacterData`), авторизацию Supabase, локальное кэширование и импорт.
2. Содержит вспомогательные UI-атомы (`CalcBadge`, `RollBadge`, `StatInput`, `RollResultPopup` и генератор `rollD20`).
3. Рендерит шапку листа персонажа со всеми кнопками быстрого действия.
4. Рендерит все 6 вкладок интерфейса (Характеристики, Бой/Атаки, Заклинания, Инвентарь, Умения, Описание).
5. Рендерит более 15 модальных окон (отдых, уровни, калькуляторы, компендиум, кукла экипировки, шаринг).

### Риски текущей архитектуры:
- Сложность навигации и чтения кода.
- Высокая вероятность непреднамеренных регрессий при точечных правках.
- Каскадные лишние ре-рендеры React компонентов.

---

## 2. Архитектурное Решение: Подход 1 (Custom Hook + Презентационные Вкладки)

Мы применяем чистую компонентную архитектуру:
- **Состояние и эффекты**: инкапсулируются в кастомный хук `useCharacterState`.
- **UI-атомы**: выносятся в `src/components/sheet/SheetUIPrimitives.tsx`.
- **Шапка и Навигация**: выносятся в `SheetHeader.tsx` и `SheetNavbar.tsx`.
- **Вкладки листа**: каждая вкладка становится изолированным компонентом внутри `src/components/sheet/tabs/`.
- **Корневой контейнер `page.tsx`**: собирает всё вместе, оставаясь компактным координатором (~250–350 строк).

```
src/
├── hooks/
│   └── useCharacterState.ts      # Стейт персонажа, автосохранение, Supabase, роллы, модалки
├── components/
│   └── sheet/
│       ├── SheetUIPrimitives.tsx # CalcBadge, RollBadge, StatInput, CustomDropdown, RollResultPopup, rollD20
│       ├── SheetHeader.tsx       # Имя, Класс, Раса, Уровень, Хиты/КД/Скорость, кнопки отдыха и левелапа
│       ├── SheetNavbar.tsx       # Навигация по вкладкам с Framer Motion
│       └── tabs/
│           ├── CoreStatsTab.tsx  # Характеристики, проверки, спасброски, навыки, хиты, КД
│           ├── CombatTab.tsx     # Атаки оружием, парный бой, боевые опции
│           ├── SpellsTab.tsx     # Параметры заклинателя, ячейки, заклинания по кругам
│           ├── EquipmentTab.tsx  # Инвентарь, вызов куклы экипировки, снаряжение
│           ├── TraitsTab.tsx     # Умения, расовые/классовые особенности, эффекты экипировки
│           └── BioTab.tsx        # Предыстория, внешность, черты характера, заметки
└── app/
    └── page.tsx                  # Главный координатор
```

## 3. Детализация Компонентов

### 3.1. `src/components/sheet/SheetUIPrimitives.tsx`
- `rollD20()`: криптографически равномерный бросок с rejection sampling.
- `RollResult`: интерфейс результата броска.
- `RollResultPopup`: всплывающее окно результата с анимацией d20, критическими метками и таймером.
- `RollBadge`: кликабельный пергаментный бейдж для проверок и спасов.
- `CalcBadge`: авторасчетный бейдж со стилем `.calc-badge`.
- `StatInput`: поле ввода с пергаментной окантовкой и лейблом.
- `CustomDropdown`: выпадающий список в средневековом стиле.

### 3.2. `src/hooks/useCharacterState.ts`
- Инициализация и состояние `char: CharacterData`.
- `update(field, value)` и `batchUpdate(updates)`.
- Синхронизация с Supabase (`/api/characters`) и `localStorage`.
- Защита импортированных персонажей от случайной перезаписи.
- Управление состоянием броска кубиков (`rollResult`, `handleRoll`, `closeRollResult`).
- Управление модальными окнами (состояния `isOpen` и хэндлеры).

### 3.3. Вкладки `src/components/sheet/tabs/*.tsx`
- Принимают типизированные пропсы:
  - `char: CharacterData`
  - `update: <K extends keyof CharacterData>(key: K, value: CharacterData[K]) => void`
  - `batchUpdate: (updates: Partial<CharacterData>) => void`
  - `onRoll: (result: RollResult) => void`
  - Обработчики кликов на модальные окна компендиума.
- Сохраняют точную разметку, CSS-классы и Framer Motion анимации.

## 4. План Безопасной Поэтапной Реализации (Zero-Regression Strategy)

1. **Этап 1**: Создать `SheetUIPrimitives.tsx` и перевести `page.tsx` на импорт из него. Запустить `tsc` и тесты.
2. **Этап 2**: Поочередно вынести вкладки в `src/components/sheet/tabs/`:
   - `CoreStatsTab.tsx`

   - `SpellsTab.tsx`
   - `EquipmentTab.tsx`
   - `TraitsTab.tsx`

   После каждого шага — компиляция и проверка тестов.
3. **Этап 3**: Создать `SheetHeader.tsx` и `SheetNavbar.tsx`.
4. **Этап 4**: Создать `useCharacterState.ts` и связать `page.tsx`.
5. **Этап 5**: Полный верификационный чеклист:
   - `npx tsc --noEmit` — 0 ошибок.
   - `npx eslint .` — 0 ошибок.
   - `npm run test:adversarial` — 100% тестов зеленые.
   - `npm run test:e2e` / Playwright visual audit.
   - `graphify update .` — актуализация графа.
