# E2E Tests (Playwright)

Директория для End-to-End тестов интерфейса персонажного листа D&D 5e.

## Команды запуска

- `npm run test:e2e` — запуск всех E2E тестов в консольном режиме.
- `npm run test:e2e:ui` — запуск интерактивного Playwright UI с визуальным плеером шагов.
- `npx playwright test --project="Mobile iPhone 14"` — запуск тестов исключительно для мобильного вьюпорта iPhone 14.
